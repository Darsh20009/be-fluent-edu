---
name: Delivery completeness
description: The user's standing expectation for completion of Be Fluent.
---

المستخدم طلب «كمل التطويرات كلها» و«مش عايز أي أخطاء». المطلوب إكمال مسارات الطالب والمعلم والأدمن والذكاء الاصطناعي وفق الخطة، لا الاكتفاء بأجزاء أو صفحات موجودة.

**Why:** The user repeated this expectation when partial work had not met the requested scope.

**How to apply:** Check the full UI-to-persistence-to-recipient workflow and role permissions before calling a feature complete. State blocked integrations, incomplete fields, missing screenshots, and unverified signed-in paths explicitly; passing static tests alone does not mean the product is complete.

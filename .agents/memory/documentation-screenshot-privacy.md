---
name: Documentation screenshot privacy
description: Rules for real page captures used in the admin Tips guide.
---

Tips images must be real page captures, not illustrations presented as screenshots. Use synthetic test accounts and redact existing users' names, email addresses, phone numbers, private notes, credential inputs, and sensitive configuration before saving any capture as a public static asset.

**Why:** Tips is restricted to ADMIN, but static documentation images can be fetched independently of the guide's page authorization. Documentation must not expose live student or staff information.

**How to apply:** Capture the actual UI after signing in through an authorized test account; preserve visible errors rather than concealing them. Keep an explicit missing-image state until a safe real capture exists, and label redacted captures honestly.
